## Remaining adaptive blocker

**740** remains deliberately rejected by the adaptive material contract. A fresh
probe confirms its translucent input is rejected before publishing a bundle.
It exports successfully and already executes in ordinary cube and exact-surface
modes. The systemic work needed to enable adaptive transmission is:

1. Advance through occupied child cells, stopping at gaps or changes of authored
   medium, including boundaries between different subdivision levels. Current
   transmission queries and skips whole parent voxels.
2. Keep authored medium identity separate from the child-colour palette slot.
   The current stack compares shading slots, so two colours of one medium can
   be mistaken for separate media.
3. Remove the absorption path's 255-slot clamp for full-width material tables.
4. Add direct boundary/medium tests, then assess rear-interface and secondary-ray
   coverage. Authored-view surfaces do not guarantee a closed transparent volume.

Execution coverage is not clean visual acceptance. The remaining lighting,
geometry coverage and fine-detail review work still applies to the wider corpus.

## Reproduce the producer gate

From the consumer checkout:

```sh
python3 tools/check_fpt_export_parity.py \
  --baseline reports/fpt-geometry-catalog-20260914/merged/report.json \
  --worker /path/to/FPT-metal-release/target/release/examples/scene_worker \
  --mandel-root /path/to/mandelbulber2 \
  --output reports/new-export-parity --jobs 2 --timeout 180
```

Use `--resume` with the same output after an interruption. The worker, baseline
and geometry request must match. Completed bundles are hash-validated; incomplete
attempts are preserved before retrying. This run recovered from a disk-space
interruption after removing rebuildable compiler intermediates and reducing to
two workers. The final gate contains no failed exports or parity mismatches.
